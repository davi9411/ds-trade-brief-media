# DS Trade Brief — mídia pública

Imagens das edições do brief diário da DS Trade (story do Instagram e status do WhatsApp).

Os arquivos em `story/` são gerados e enviados automaticamente pelo fluxo de publicação do brief, e as edições com mais de 10 dias são apagadas. A pasta `test/` guarda só imagens de teste. Este repositório não guarda dados pessoais nem segredos: tudo aqui é público.
